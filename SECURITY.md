# Security Policy

## Supported Versions

The following versions of Agent Operations Center (AOC) receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| `< 0.1` | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within Agent Operations Center (AOC), please report it privately:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability directly to **security@paterski.com** or use GitHub's **Private Vulnerability Reporting** feature.
3. Include details of the vulnerability, steps to reproduce, and potential impact.

We aim to respond to security reports within 48 hours and provide a remediation timeline.
